# Seasonal Agriculture Performance Analysis

## Project Overview

This project analyses agricultural data across different farming seasons to understand how seasonal conditions are associated with agricultural performance.

The analysis focuses on Kharif, Rabi and Zaid seasons and examines environmental conditions, crop performance, irrigation, resource usage, water efficiency, disease and pest risk, and economic outcomes.

## Objectives

- Understand the agricultural dataset
- Clean and prepare the data
- Compare agricultural performance across seasons
- Study crop-season behaviour
- Analyse irrigation and resource usage
- Investigate environmental relationships
- Evaluate economic performance
- Validate important findings statistically
- Develop evidence-based recommendations

## Dataset

The dataset contains agricultural records covering different crops, seasons, geographical areas, environmental conditions, farming inputs, agricultural outcomes and economic measures.
